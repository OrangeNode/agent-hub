# 用户端聊天侧栏账户菜单设计

## 背景

用户端聊天页 `user-web/src/views/ChatView.vue` 左下角账户区当前直接展示头像、加粗用户名和“退出”按钮。这个区域视觉边界偏重，用户名使用 `<strong>` 造成字重过高，和侧栏里“最近会话”的轻量风格不一致。

## 目标

- 将左下角账户区改为更轻量的账户按钮。
- 用户名不再加粗，保持普通字重。
- 将退出入口收进账户菜单，减少底部区域的按钮感。
- 保持现有登出行为不变。

## 方案

账户区采用“账户菜单”方向：

- 底部显示一个可点击的账户按钮，内容为头像、用户名和下拉箭头。
- 用户名使用普通文本标签和 `font-weight: 400`，并保留溢出省略。
- 账户按钮使用浅色背景、轻微阴影或边框、8px 圆角，和侧栏色彩保持克制。
- 点击账户按钮后，在按钮上方弹出小菜单。
- 首版菜单只包含“退出登录”一项，调用现有 `handleLogout`。

## 组件和状态

改动集中在 `ChatView.vue`：

- 新增 `accountMenuOpen` 响应式状态。
- 账户按钮点击时切换菜单显示。
- 根容器已有点击关闭会话菜单的行为，需同时关闭账户菜单。
- 账户按钮和菜单内部点击使用 `.stop`，避免刚打开就被外层点击关闭。

## 交互细节

- 点击账户按钮：打开或关闭菜单。
- 点击菜单外部：关闭菜单。
- 点击“退出登录”：执行现有退出逻辑。
- 账户菜单只在侧栏展开时显示；侧栏折叠时沿用当前折叠行为，不新增独立入口。

## 样式细节

- 头像降低视觉重量，使用浅底色和中等字重。
- 用户名普通字重，字号延续当前 14px 左右。
- 菜单定位在底部账户按钮上方，宽度和按钮区域协调。
- 菜单项使用文本按钮样式，危险程度不做强红色块，仅在文字颜色上表达退出动作。

## 测试与验证

- 运行 `user-web` 类型检查或构建，确认模板和 TypeScript 通过。
- 运行现有用户端测试中覆盖认证/登出的相关用例。
- 在浏览器验证账户按钮、菜单打开关闭、退出入口可点击，检查用户名不再加粗。

## 非目标

- 不新增个人资料页、用户偏好设置或账号管理能力。
- 不调整侧栏整体布局、最近会话样式或聊天主区域。
- 不改变认证、路由跳转和会话清理逻辑。
